# 创作工作台

`/create` 左侧设置参数，右侧查看作品和版本。登录后沿用现有模型、参考图、任务和计费接口。

## 从描述生成

选择「灵感生图」「参考生图」或「修改图片」，再填写描述。参考生图和修改图片需要选择图片；切回灵感生图会保留已选图片，但不会提交它们。添加新参考图会切换到参考生图。

用途模板、视觉风格和图中文字语言通过提示词预设实现，不增加模型参数。切换用途保留自写描述，「填入示例描述」会替换描述。展开「模型与提示词」可检查实际提交的完整提示词，长度限制包含预设补充内容。尺寸、参考图能力与数量仍以后台模型配置为准。

## 生成数量与防刷

1／2／4 张是快捷选项，也可输入任意正整数张数；不设每分钟或每日生成/消费配额。网页、普通 API、画布与 MCP 共享账号余额和账务规则，模型输入能力与 Agent 用户自定单次消费上限仍生效。

批量请求每组最多 4 个并行，组间至少间隔 250 ms，逐组提交并立即显示已接受的任务；这只是请求调度，不限制总张数。可点击「停止继续提交」，已接受任务继续生成。遇到余额不足、鉴权、防刷拒绝或结果不明时停止后续提交，保留已接受任务，不自动换请求 ID 重试。刷新恢复会读取全部进行中任务，不再截取前 20 条。

进入或刷新创作台时默认显示新绘图草稿；进行中任务仍会恢复并继续同步，但结果图不会自动加载。选择顶部「最近绘图」中的批次后才加载其候选图和原图。结果区只展示当前选中的一批，其他批次通过顶部切换。每批顶部集中展示已完成张数、等待中的任务及预扣／结算／退款金额，进度条按真实结束的任务数更新，失败也计入已结束数，并单独标明成功和失败张数；不再额外展开一组重复的任务图片。改图任务计入原批次的进度与计费。单张的失败原因、全额退款、重新生成和收起操作直接放在选中结果中。

单张生成直接展示作品，不显示候选图编号、重复缩略图或版本记录；只有实际继续修改后才显示原图 V1 和修改结果 V2+。多张生成则以「候选图 1／2／…」并排展示，便于比较挑选；它们是相同参数下的独立抽卡，不是递进版本。每次提交独立显示为一条绘图记录，即使提示词相同，不同提交批次也不会合并。批次归属保存在当前浏览器，缺失时按独立任务展示，不根据提示词猜测。

排队和生成中的占位区域会轮换画室趣话，现有 98 句；每张任务独立抽句子和切换间隔，约 5～8 秒更新一次，不强制不同图片互相避让，允许自然撞句，但同一张图不会连续重复上一句。选中图的大预览与缩略卡共享这张任务的文案，轮询更新或排队转生成不会重新抽取初始文案，完成或失败后停止轮换。文字短暂淡入并轻微上移，支持系统「减少动态效果」；屏幕阅读器不会被轮换文案反复打断。趣话是等待时的娱乐文案，不代表模型真实阶段，也不改变顶部的真实任务进度。大预览仍保留结果自动同步、防止重复提交的提醒。

## 换一个主题

点击工作台顶部或结果底部的「新绘图」，清空描述、已选参考图、用途、风格及文字语言预设，回到灵感生图并聚焦输入框；沿用所选模型、尺寸和生成数量。已有作品保留在「最近绘图」及服务器历史中，正在生成的任务继续同步，完成时不会打断新描述或切回旧批次。输入新内容后需手动点击「开始创作」，才会提交独立新批次；新建本身不会产生任务或扣费。

切回旧批次只切换结果，不替换左侧正在写的描述。继续修改某张旧图仍须使用该图的「继续修改」入口，才会形成版本分支。上传参考图或提交任务时暂不可重置表单；未知改图请求的确认入口会保留，不因新绘图而丢失。

生成入口仅保留账号级秒级洪峰防护，默认同一秒最多 60 次新请求，网页/API/画布/MCP 共同计数。超出返回 `429`，网页 API 带 `Retry-After: 1`，拒绝请求不扣费。它不是分钟配额，也不能代替 CDN 的攻击流量防护；登录、验证码与 OAuth 端点的防滥用规则继续生效。

## 连续修改与版本

选中任意已完成候选图，输入修改要求后生成一张新图，才形成该候选图的修改分支；原图在分支内记为 V1，修改结果从 V2 开始编号，其他候选图的版本独立计算。修改结果仍归属原候选图所在批次；选中它时仅显示这张候选图的原图和修改记录，旧版本保留，也可从旧版本分叉。修改会把选中图片上传为参考图，再由模型重绘整图，效果取决于模型；目前没有局部蒙版或图中文字直接编辑功能。参考图空间不足时会报错，不会静默淘汰旧图片。

版本关系按账号保存在当前浏览器的 localStorage，最多保留 100 条；刷新后通过鉴权任务接口恢复详情，但默认不加载这些图片。工作区最近绘图由本地保留的批次和版本关系组成，不代表服务器上的全部任务；完整任务记录在「全部历史」。版本关系不跨设备同步，也不延长原图保留期。清理网站数据会丢失本地关系，服务器生图历史仍保留。

改图提交前先保存完整参数与请求 ID。网络中断导致结果不明时，点击「确认上次改图任务」用相同参数和请求 ID 确认，不重新上传或创建另一付费请求。确认前无法发起另一改图任务；本地存储不可写时阻止提交并显示错误。明确失败的任务可重试，仍使用原父版本和原修改提示词。

## 加入无限画布

选择新建或已有本地画布，再点击「加入画布并打开」。工作台取得仍有效的鉴权原图，保存本地素材副本，并追加图片、来源笔记和连接好的生成节点。保存成功后才打开画布，不自动运行生成节点或扣费。

追加遵守画布节点、素材、128 MiB 容量及多标签页修订检查；失败时保留原画布。生成节点可单独选择 1K、2K、4K 尺寸和生成数量，清晰度由渠道配置控制；参数会随本地项目保存，并随生成请求提交。已保存的本地副本不再依赖原图期限，但清理浏览器数据仍会删除，请定期导出。云端能力与完整限制见 [无限画布](v0.20.0-release.md)。

## 本地交互预览

无需真实上游或数据库即可验证页面流程。需要 Python Pillow；本地已有依赖可直接使用，不要为预览修改生产依赖。

```bash
python3 scripts/preview-creation-mock.py
```

验证等待文案和四张图独立轮换时，可追加 `--generation-seconds 90`，让 Mock 任务等待 90 秒再完成；默认仍为 1.7 秒。此参数只影响本机假图预览。

另开终端：

```bash
cd frontend
VITE_API_PROXY_TARGET=http://127.0.0.1:18931 npm run dev -- --host 127.0.0.1 --port 5174
```

访问 <http://127.0.0.1:5174/create>，Mock 账号为 `demo` / `Painter123!`。生成结果是带 `MOCK PREVIEW` 标记的假 PNG；服务仅监听本机，数据随进程退出清空，与真实数据库、上游和积分无关。Mock 账号不能登录生产。

## 实现与发布边界

版本关系及待确认请求由 `useCreationVersions.ts` 管理，账号或会话变化会中止原图请求并忽略旧异步结果；画布适配使用现有 IndexedDB 保存机制。批量生图仍复用按张提交接口，不增加数据库迁移。生成响应不再返回 `rate_limit_remaining`；防刷配置见 [配置与部署指南](setup-and-operations.md)。

前端回归命令：

```bash
cd frontend
node --experimental-strip-types --test tests/*.test.mjs
npx vue-tsc --noEmit -p tsconfig.app.json
npm run build
```

生产发布沿用 [正式版本自动部署](continuous-deployment.md)，按仓库当前迁移版本执行就绪检查。部署后检查真实页面、模型列表、账号隔离与现有媒体读取；readiness 和 Mock 预览不能代替真实上游生成验收。
