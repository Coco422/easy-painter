# v0.19.0 作品管理与媒体生命周期

## 已确认的产品规则

- 导航：社区灵感、创作台、生图历史、个人画廊、收藏；移除重复的公开画廊入口，保留分享地址。
- 生图历史保留所有任务状态和过期文字记录；加入个人画廊与投稿社区是两个独立动作。
- 个人画廊按用户公开总开关展示。投稿需要先开启总开关并确认公开图片与提示词，由管理员审核；未主动投稿的作品不进入审核队列。
- 待审不延长原图寿命；关闭总开关撤回未审核投稿。审核通过后社区副本独立长期保存，关闭总开关或删除原作不影响社区副本。
- 收藏自己、他人及社区作品，保存引用而不复制图片或延长有效期；同一原作与收录版合并为同一收藏。失效收藏保留不含受限内容的占位，可清理。
- 非 VIP 新生成图从完成、新参考图从上传计算 48 小时；上线时仍有效的非 VIP 存量统一改为迁移后 48 小时。VIP 维持既有 30 天配置和期限。过期或正在清理的对象不复活。
- 已收录作品的画廊与收藏统一引用社区副本；原始文件照常到期清理。
- 卡片显示实际到期时间或长期保存。已知失效不请求图片、下载或重试；普通作品撤回后新的访问立即拒绝。
- 列表使用最长边 640px WebP 缩略图，详情按需读取原图。稳定媒体地址、鉴权后 ETag/304；普通作品不进入共享缓存。

## 验收门禁

权限覆盖所有者、其他用户及游客；隐藏提示词不泄露；收藏不授权访问；待审到期与收录并发安全；原图清理不破坏社区副本；关闭公开总开关后的 304 也必须重新鉴权。新旧留存迁移不复活过期文件，VIP 不受影响。已知失效资源零图片请求，首屏仅缩略图。
