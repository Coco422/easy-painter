# v0.20.0 无限画布

本版保留 `/create` 普通创作台，新增 `/canvas` 列表与 `/canvas/:id` 编辑器。实现参考 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)，来源版本、适配范围与 MIT 许可全文见 [第三方声明](../THIRD_PARTY_NOTICES.md)。PSD、多人协作和自动执行复杂工作流不在本版范围。

## 使用方式

登录后从导航进入「无限画布」。创建画布，添加文本、图片或生成节点；支持图片文件选择、拖放和粘贴。图片与文本右侧的连接点可连接到生成节点；选中图片后的「继续创作」会自动创建并连接新的生成节点。连接素材组会按画布中子节点顺序使用组内资源；直接参考图按连线建立顺序去重提交。

v0.20.1 交互优化：按住参考图、已生成图片、文本或素材组右侧的连接点，即可拖出预览线；悬停生成节点时高亮，松开完成连接。拖到空白处松开或按 Esc 取消，也可继续使用「点击连接点，再点击生成节点」的方式。此次升级沿用 Flyway V10，无新增数据库迁移。

- 拖动节点标题或图片移动；框选、Shift/Cmd/Ctrl 多选后可打组；拖动组标题一起移动子节点，解散组保留子节点。
- 按住空格或使用移动工具平移，滚轮围绕鼠标位置缩放；右下角可调整缩放或显示全部。
- 双击空白处添加文本，双击连线移除连接；Delete 移除选中节点，Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 重做。
- 一次可生成 1、2、4 张图片。复用现有模型、参考图、任务和计费接口；关闭画布不取消任务，重新打开继续轮询已知任务。
- 请求 ID 与提交参数先保存本地再提交。网络中断导致结果不明时，使用「确认任务」以同一个幂等键重试；不会自动生成一个新的付费请求。
- 移除节点不删除生图历史或取消付费任务。撤销只作用于节点布局与连线，任务记录和已经取得的素材独立保留。

## 本地保存

画布结构与图片 Blob 分别存入 IndexedDB 的 `projects`、`assets` store，按账号隔离。素材采用内容 SHA-256 标识，画布不持久化临时 `blob:` URL。生成结果在远程媒体仍可用时下载为本地副本；取得本地副本前，服务端媒体保留期仍然生效。

HTTP 访问缺少 `crypto.randomUUID` / `crypto.subtle` 时，使用浏览器 `getRandomValues` 及按需加载的 `@noble/hashes` 完成本地 ID 与 SHA-256 计算；哈希在两种环境中一致，生成请求的幂等键仍使用安全随机值。

本地修改延迟 450 ms 合并保存；多标签页使用本地修订号检查冲突，冲突时保留当前编辑内容并提示先导出，不自动覆盖另一个标签页。保存失败或浏览器空间不足时明确提示。浏览器可能清理网站数据，本地保存不等于备份。

「导出项目」生成 `.epcanvas.json`，包含画布与所有引用的图片，素材以 base64 封装。导入时验证版本、节点引用、素材哈希和大小，并创建独立副本。导入不会自动提交未完成的生成请求。每张画布最多 300 个节点、1000 条任务记录、1000 份素材、128 MiB 引用素材；单图最多 12 MiB、4000 万像素，支持 PNG/JPEG/WebP。

## VIP 云端能力

普通用户使用本地画布。后端根据当前用户的 `vip` 分组及分组启用状态校验云端写入资格；不信任前端分组标识。

VIP 在具体画布上点击「开启云端同步」后，先完成本地保存，再上传未存在的素材并保存画布结构。后续修改等待 5 秒空闲后合并同步，也可手动立即同步或关闭自动同步。跨设备恢复从画布列表的「云端画布」进入。

- 首版每账号最多 20 张云端画布、256 MiB 云端素材，每张画布最多 128 MiB、1000 份素材。限制定义在 `backend/app/api/canvas_routes.py`，暂未提供后台配置 UI。
- 素材按画布与内容哈希去重，重复同步已有素材不再上传；云端结构使用 `expected_version` 乐观版本检查。冲突、权限失效或同步失败会停用自动同步，保留本地编辑，用户可对比云端副本后重试。
- 云端恢复若遇到同 ID 的本地画布，会创建新的本地副本，不覆盖本地内容；恢复后的副本默认不开启自动同步。
- 用户离开 VIP 分组后无法新增或修改云端项目，但仍可列出、读取、恢复、导出和删除自己的已有项目。
- 云端项目素材独立保存，不沿用普通生成图片的 48 小时过期策略；保留到用户删除云端项目或符合现有规则的账号删除。移除节点后曾上传的素材暂时仍保留并占用额度；删除整个云端项目才释放这些素材。
- 云端项目删除与素材删除队列在同一数据库事务中记录；Dispatcher 后续清理 RustFS 对象。只有所属账号可读取云端项目与素材，响应禁止共享缓存。

## 数据库与升级

新增 Flyway `V10__cloud_canvas.sql`，仅创建 `canvas_projects`、`canvas_assets`。不迁移或修改现有作品、账务和用户组配置。健康检查期望版本同步为 `10`。

1. 按 [备份与灾难恢复](backup-and-disaster-recovery.md) 完成生产备份。
2. 发布时创建新的 `v0.20.0` 版本标签，等待配套镜像构建完成；迁移、API、Worker、Dispatcher 与前端同步升级。
3. 先完成 Flyway V10，再启动应用并确认 readiness。开发数据包若按 V9 导入，导入完成后也要执行 V10 才能配合本版 API。
4. 验证普通账号本地创建与恢复，VIP 云端上传、恢复、降组后只读与删除，以及原有 `/create` 生成流程。

Flyway 不做向下迁移。回退应用时保留 V10 表与已上传的云端素材，不删除用户数据；旧版的严格 schema readiness 期望为 V9，会报告不兼容，因此生产回滚必须按备份恢复方案评估，不能只切换旧镜像。
