# 创作工作台重设计 · 试运行说明

分支：`ray/workspace-redesign`
配套设计稿：[workspace-redesign-draft.md](./workspace-redesign-draft.md) · [workspace-redesign-draft.html](./workspace-redesign-draft.html)

## 启动

```bash
make frontend
```

打开 http://localhost:5173/create 。左下角会浮出「设计预览 · Mock」面板，点任意场景即可切换，页面会自动刷新并播种对应的登录态与作品。

Mock 只在 `vite dev` 下生效（`mock/plugin.ts` 注册为 Vite 中间件，`src/lib/dev-mock.ts` 负责播种会话）。生产构建不会包含它：入口处的 `import.meta.env.DEV` 判断会把这段代码摇掉，中间件也只在 `apply: 'serve'` 时挂载。

- 退出 mock：面板底部「退出 mock」，或访问任意页面加 `?mock=off`
- 重新进入：清掉 `localStorage['easy-painter:dev-mock-disabled']` 后刷新
- 重放计时：面板底部「重放计时」，把带时间的场景（生成中、排队）从头再来一遍

## 场景清单与预期

| 场景 | 验证点 |
|---|---|
| 空闲 · 有历史 | 右栏为空闲引导（一句 h3 + 一句说明 + 一条提示），结果区不再是四张模板卡 |
| 空闲 · 全新账号 | 无任何作品时的最小状态 |
| 单张生成中 | 画布内呼吸光斑 + 一句 quip + 固定说明；左上「生成中」胶囊；12 秒后自动变成结果图 |
| 4 张候选 · 混合状态 | 候选栏 4 个 84px 缩略图：2 个完成、1 个绘制中、1 个失败已退款；15 秒后全部结束。检查状态行「已生成 N / M 张 · N 张生成中」、计费只出现一次 |
| 4 张全部进行中 | 4 个缩略图同时转圈；30 秒后依次完成 |
| 长排队 | 排队与绘制中在胶囊文案上可区分（这是旧实现没有的） |
| 修改分支 V1 → V2 → V3 | 选中 V3；底部版本条可切回 V1 / V2 分叉；「继续修改 V3」 |
| 失败并退款 | 画布占位 + 失败原因 + 「N 丝已全额退回余额」+ 重新生成 / 收起 |
| 图片已过期 | 媒体过期后的占位与到期提示 |
| 图片加载失败 | 媒体接口 404，检查占位与一次性重试 |
| 余额不足 | 提交返回 402：就地提示「还差 N 丝」，不跳转、不新增任务 |
| 提交缓慢 | 点击「开始创作」后按钮进入提交中状态 2.5 秒 |
| 提交结果未知 | 服务端 503：出现「上次改图的提交结果尚未确认」保护路径，不会重复扣费 |

## 这一版改了什么

- **输入面板**：去掉了页面标题块、三选一模式按钮、四张模板卡。现在是「描述框 → 参数胶囊行 → 提交」。用途 / 风格 / 图中文字 / 尺寸 / 数量 / 模型全部收成一行胶囊，已启用的预设以可移除的标签出现。
- **模式推导**：粘贴或拖入图片自动进入参考生图，清空参考图自动回到灵感生图，不再需要手动选。
- **计费**：只保留提交按钮下方一行（`5 丝 × 2 张 = 10 丝` + 余额），删掉了原来的三行解释。
- **结果区**：小方形编号 rail（最近绘图）+ 状态行 + 候选缩略图 + 画布 + 一行参数与操作。删掉了 `batch-overview` 的三连报账、`candidate-grid` 的大卡、单张图也出现的「修改记录 1」。
- **进度**：仍然只有真实进度（已完成 / 总数），没有模拟百分比。
- **字体**：`CreatePage` 的 `PingFang SC` 硬编码已移除，工作台回到全站 `--font-body`。
